# Estrategia de ramas

Para este proyecto se utiliza la estrategia GitFlow, ya que permite organizar el desarrollo de manera estructurada mediante el uso de ramas específicas para cada tipo de trabajo.

## Ramas principales

- main: contiene la versión estable del proyecto
- develop: contiene los cambios en integración antes de pasar a producción
